# XQ 腳本：黑美人／帥大叔

把財富守護星（TAURAS）的「黑美人」選股公式轉成 XQ 全球贏家的 XS 腳本，包含收盤後選股與盤中即時警示。

## 核心邏輯

以 2026/09/24 跟財富守護星逐檔比對後採用的版本（19 檔中命中 16 檔）：

> **今天收盤價突破前 3 天最高價**，且（**寶塔翻紅** 或 **爆量 1.5 倍 + MA5 > MA10**）
> 濾網：股本 ≤ 20 億、成交量 > 1000 張

- **寶塔翻紅**：過去 100 天沒有突破過，或最近一次「跌破前 3 天最低價」比最近一次突破更近（由空翻多的第一次突破）
- 前 3 天高低點不含今天，對應原公式 `@MAX(-3,3,HIGH)`

## 腳本一覽（`選股/` 資料夾）

| 檔案 | XS 類型 | 用途 |
|---|---|---|
| `黑美人_寶塔翻紅或爆量.xs` | 選股 | 收盤後選股，`DaysAgo`／`ScanDays` 可往回掃描幾天內的觸發 |
| `黑美人_盤中警示.xs` | **警示** | 策略雷達「帥大叔」使用，盤中突破即通知並顯示突破價 |
| `黑美人_突破前預警.xs` | 警示 | 股價距離寶塔翻紅突破價 2% 內先通知，方便預掛觸價單 |
| `族群資金流入警示.xs` | 警示 | 監控類股指數：量比 ≥ 1.5、漲幅 ≥ 1.5%、強於大盤 1% |
| `帥大叔_診斷.xs` | 警示 | 排查用：每檔都觸發，訊息列出股本、K 棒數、各條件結果 |
| `小強_對照.xs` | 選股 | 跟財富守護星比對用，`BranchMode` 可切換 0/1/2/3 |

> 警示腳本必須在 XS 編輯器的「**警示**」分頁建立。建成「選股」類型的話，策略雷達不會觸發，且 `RetMsg` 會編譯失敗。

## 策略雷達設定（帥大叔）

| 欄位 | 設定 |
|---|---|
| 腳本 | 帥大叔_警示（警示類型） |
| 多空方向 | 多方 |
| 觸發設定 | K 棒內單次觸發 |
| 指定頻率 | 日、原始值、逐筆洗價 |
| 執行商品 | 組合 → 台股上市櫃類股 → **普通股全部** |
| 音效 | 自選，例如 LTOL.wav |

- 狀態顯示「部份執行」是正常的：近一年上市、歷史 K 棒不足約 130 根的新股會報錯誤 5029 而跳過。
- XQ 必須在盤中保持開啟，重開 XQ 後要確認策略仍在執行。

## 已知問題與排查（2026/09/30）

收盤後選股能選出 23 檔，但盤中策略雷達沒有觸發，原因尚未確認。下個交易日盤中同時做三個測試：

| 測試 | 做法 | 結果判斷 |
|---|---|---|
| A | 啟動系統策略「當日量突破」 | 也不觸發 → 體驗版限制盤中警示，需升級方案 |
| B | 帥大叔參數「股本濾網」改 0 | 開始觸發 → 警示腳本讀不到股本，需改寫股本過濾方式 |
| C | 帥大叔_診斷，只放 6155、6727、6925 | 看訊息裡的股本、K 棒、突破、翻紅、爆量數值找出卡住的條件 |

另外，XQ 體驗版的選股每天有執行次數限制。

## 跟財富守護星的已知差異

- 財富守護星的成交量略低於 XQ（可能未含盤後零股／鉅額），門檻附近的股票會有出入。
- 可能有還原權值差異（大綜、由田、M31 在 XQ 原始價下未突破），尚待用「還原日」頻率驗證。
