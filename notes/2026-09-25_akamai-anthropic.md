# Akamai × Anthropic 116 億美元多年期合約（2026-09）

來源：[Akamai IR 新聞稿](https://www.ir.akamai.com/news-releases/news-release-details/akamai-announces-116-billion-multi-year-agreement-anthropic)、[Reuters 轉載](https://www.aol.com/articles/akamai-anthropic-sign-11-6-200943000.html)、[Benzinga](https://www.benzinga.com/trading-ideas/movers/26/09/61985737/akamai-stock-soars-on-11-6-billion-anthropic-deal)、[8-K Ex.99.1](https://www.sec.gov/Archives/edgar/data/0001086222/000119312526401048/d288154dex991.htm)

## 重點事實

| 項目 | 內容 |
|---|---|
| 合約金額 | 116 億美元，合約期 7 年 |
| 用途 | Anthropic 使用 Akamai Cloud 的分散式基礎設施與軟體，承接快速成長的 **CPU** 工作負載 |
| 擴大空間 | 最多再加 90 億美元，潛在總承諾約 200 億美元 |
| 初始承諾對應總 capex | 約 55 億美元 |
| 2026 capex | **增加約 17 億美元**，用於事先鎖定、預購支援本案的零組件，**以記憶體為主** |
| 採購方式 | Akamai 已授權 Jabil 代購約 17 億美元記憶體零組件，Jabil 收貨後由 Akamai 支付供應商發票 |
| 營收指引 | 年度營收預測不變（營收貢獻落在後續年度） |
| 認股權證 | 可認購無表決權、可轉換的 Series B 特別股，轉換後約 770 萬股普通股（最高約已發行股數 5%），履約價每股 111.33 美元 |
| 歸屬條件 | 約 2% 隨本次 116 億承諾歸屬；其餘約 3% 需合作再擴大（最多 90 億）才會歸屬 |
| 市場反應 | 盤後大漲約 16% |

## 解讀

1. **記憶體先卡位**：17 億美元提前預購、且透過 Jabil 代購並付款，說明記憶體（DRAM/伺服器模組）供給吃緊，雲端業者願意先付現金鎖貨。這也印證 AI 需求已從 GPU 延伸到 CPU 伺服器的記憶體用量。
2. **CPU + 從 core 延伸到 edge**：Agent 類工作負載需要大量 CPU（工具呼叫、沙箱、編排、推論前後處理）。Akamai 的分散式節點可以把算力放在離使用者較近的位置，**降低延遲**，同時**分散擴容**，不必集中在少數大型資料中心。
3. **認股權證綁定成長**：Anthropic 先拿到約 2%，要擴大採購才拿到剩下 3%。雙方利益一致，但對 AKAM 股東會有稀釋。
4. **對 Akamai 的財務影響**：capex 先付、營收後認，短期自由現金流承壓；7 年合約帶來營收能見度，市場目前把重點放在後者。
